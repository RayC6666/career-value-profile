# 职业能力画像与简历应用

`career-value-profile` 是一个中文 AI skill：从长期经历和工作材料中理解个人判断、能力与成长，形成职业价值画像，再用于用户选择的简历优化、岗位匹配、职业发展或面试准备。

当前为 **V1.2 预览版**。它是一套分阶段的分析与协作指令，不是独立应用，也没有内置统一的文件转换引擎。

## 适合解决什么问题

- 经历很多，但难以概括自己的能力、价值和成长主线。
- 简历像工作事项清单，看不见个人判断与贡献。
- 希望区分已有能力、可迁移经验和需要验证的部分。
- 希望在不夸大事实的前提下形成有说服力的职业表达。

仅需修改几句话或格式时，可按局部任务执行，不强制重做完整流程。

## 核心方法

**情境 → 责任 → 判断 → 实现 → 变化。**

业务规模提供背景，个人角色和判断解释贡献，实际变化提供依据。再通过跨经历比较和时间线，理解能力组合及成长。资料缺失不直接等于能力不足，过去意愿不直接代表当前选择。

## 开始使用

1. 将包含 `SKILL.md` 的完整目录导入支持此类技能的 AI 客户端，安装方式以该客户端为准；只复制主文件会丢失参考流程。
2. 为自己的资料选择一个独立的私有工作区，不把真实简历或分析结果放进公开仓库。
3. 调用技能并说明目标，例如：

```text
请使用 $career-value-profile，帮助我梳理长期经历和职业能力，之后用于简历优化。
先确认目标与原则，我会分批提供资料，等我说发完后再处理。
```

如果客户端不支持 `$` 调用，可要求助手读取 `SKILL.md`，并按相对链接加载相关参考文件。是否支持这种使用方式及持久化，需要由实际环境确认。

## 可以提供什么资料

已有简历、述职、复盘、工作记录、方案、结果反馈、学习经历、当前意愿及目标岗位材料均可。没有文件也可从口述经历开始，不要求一次交齐。

资料收到不等于已经完整读取。每批提交结束后，先逐份转换成Markdown、核对覆盖和缺失，再整理摘要。复杂文件需要相应读取工具；扫描件可能需要视觉识别或OCR。工具缺失、损坏或内容不可读时，会说明缺口并请求替代材料或限定范围的推进确认。

模板由助手预填已知信息，用户只补充和纠错。参见 [模板字段与私有项目结构](references/templates.md)。

## 流程与七个确认节点

1. 核心目标与原则理解。
2. 资料接收结束。
3. 资料转Markdown并检查后，确认资料摘要。
4. 核心目标再次校准。
5. 画像初稿确认。
6. 画像终稿确认。
7. 应用分支选择。

节点之间开展分析和定向提问；重要事实或目标改变时，只重新核对受影响部分。用户可以修改流程、暂停或选择局部任务。

## 最终能得到什么

核心成果为职业价值画像、能力图谱及主张与证据的对应关系。画像确认后，可选择：

|应用|成果|
|---|---|
|简历优化|通用或方向简历、修改依据、待核信息|
|岗位匹配|独立岗位要求、匹配证据、风险与验证办法|
|职业发展|责任与能力变化、实践机会、阶段验证计划|
|面试准备|案例和问答、追问、评审与表达修订|

没有具体JD时可以生成通用简历，但不声称完成岗位匹配；模拟回答不等于用户真实临场表现。

## 边界与隐私

- 不编造职级、规模、数字、因果或已完成成果。
- 不把团队结果全部归于个人，也不因记不清数字而否定能力。
- 不诊断人格、不保证职业成功或面试通过。
- 不自动投递、联系第三方、上传资料或发布内容。
- 文件与模型服务的实际数据处理方式取决于所用客户端和服务。本技能不能替代其隐私政策，也不能承诺所有运行环节均离线。
- 提交问题反馈时，仅使用去标识化说明或明确虚构示例，不附真实简历、联系方式、客户数据及私人路径。
